§ 05

纸上的推导

以上所有图形背后的五段推导——从坐标化到正弦定理与 Heron 公式。

01 · COORDINATES

坐标化

B(0,0), C(a,0), A(t,h)

把底边放到 x 轴上：B 在原点，C 在 (a, 0)，平行线就是 y = h。底边与高固定后，唯一的自由度是横坐标 t——整场实验都在这一个参数上进行。

02 · ARCTANGENT

三个角

∠B = atan2(h, t)
∠C = atan2(h, a−t)
∠A = 180° − ∠B − ∠C

底角就是对边与邻边之比：在 B 处看 A，横距是 t；在 C 处看 A，横距是 a−t。用 atan2 而非 tan，t 越出 [0, a] 时的分支会自动接对。

03 · THE 2-SIMPLEX

角度空间

x + y + z = 180°, x, y, z ≥ 0

内角和把 P 压在第一卦限里的正三角形截面上。t 从 −∞ 扫到 +∞，P 沿一条开曲线从 (0°,180°,0°) 走到 (0°,0°,180°)；t = a/2 时 ∠B = ∠C，∠A 最大。

04 · LAW OF SINES

正弦定理

a / sin∠A = b / sin∠B = c / sin∠C = 2R

两角加任一边（或高），第三角与全套边长立即可解。已知两边与一对角时可能交出两个三角形——几何上是射线与圆的两个交点，这就是「两解」的来历。

05 · COSINES & AREA

余弦与面积

a² = b² + c² − 2bc·cos∠A
S = √[s(s−a)(s−b)(s−c)], s = (a+b+c)/2

三边用余弦定理定角、Heron 公式定面积；两边夹一角则反过来由余弦定理补出第三边。三条高由面积反推：hᵦ = 2S/b，hₒ = 2S/c。

WHICH TRIPLETS SUFFICE?

哪些组合够用

至少三个独立量才能定下一个三角形：三边（SSS）；两边夹角（SAS）；两角加任一边或高（AAS / AAH）； 两边一对角（SSA）可能有零、一或两个解。只有三个角（AAA）定型不定量； 而像「B、c、h」这样的组合彼此不独立，永远差一个自由度。
